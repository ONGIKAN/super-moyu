# 超级墨影 · 结构交互展示（28 号赛车）

**在线体验 / Live demo：** https://ongikan.github.io/super-moyu/

安徽理工大学方程式赛车队 28 号燃油方程式赛车的 three.js 结构交互展示：

- 「整车 / 12 个分类」一键切换：车身覆盖件、车架座椅、空气动力学、悬架系统、转向系统、车轮轮胎、动力总成、燃油系统、传动系统、进排气系统、冷却系统、标准件；
- 点分类后该部件正常显示，其余部件为淡淡半透明（结构层次一目了然）；
- 支持等轴 / 前 / 侧 / 顶 / 后视角、自动旋转、拖拽旋转、滚轮缩放；手机支持底部栏布局。

本仓库为「黑盒发布」：仅包含压缩混淆后的运行文件与不透明二进制资产，不含工程源码、Blender 管线与元数据。
